Meta WhatsApp Cloud API Ayarlari

Meta for Developers > WhatsApp > API Setup sayfasindan kopyalayin
Kaydetmek icin yeni token girin. Bos birakirsaniz mevcut token korunur. Gecici token 24 saat gecerlidir, kalici token icin System User olusturulmasi gerekir.
Nasil Kurulur?
  1. developers.facebook.com adresinden uygulama olusturun
  2. WhatsApp urununu ekleyin (API Setup sayfasi acilir)
  3. Phone number ID ve Access Token’i kopyalayin
  4. Test edilecek numarayi "Manage phone number list" ile dogrulayin
  5. Yukaridaki formu doldurup Kaydet’e basin
  6. Test mesaji gondererek kontrol edin

Twilio WhatsApp Ayarlari

Twilio Console > Account Info bolumunden kopyalayin
Kaydetmek icin yeni token girin. Bos birakirsaniz mevcut token korunur.
Twilio Nasil Kurulur?
  1. twilio.com/try-twilio adresine gidin
  2. Ucretsiz hesap acin ($15 kredi gelir)
  3. Console’dan Account SID ve Auth Token’i kopyalayin
  4. Sol menuden Messaging > Try it out > Send a WhatsApp message’e gidin
  5. Telefonunuzdan join <kelime> yazarak Sandbox’a katilin
  6. Yukaridaki formu doldurup Kaydet’e basin
  7. Test mesaji gondererek kontrol edin
Fiyatlandirma
Baslangic kredisi$15 Ucretsiz
Mesaj ucreti (TR)~$0.005 / mesaj
$15 ile kac mesaj~3.000 mesaj
Uretim icinWA Business dogrulama gerekli

Kendi WhatsApp Hesabim

Kendi WhatsApp hesabinizla baglanin. Ucretsizdir ancak sunucunun surekli acik olmasi gerekir.

Durum kontrol ediliyor...

WhatsApp'i baglamak icin telefonunuzdan QR kodu okutun:

WhatsApp > Bagli Cihazlar > Cihaz Bagla

WhatsApp bagli ve hazir!

Randevular onaylandiginda otomatik mesaj gonderilecektir.

Bilgi
  • Sunucu ilk basladiginda terminalde QR kodu gozukur
  • Telefonunuzdan QR’i okutun
  • Oturum kapanirsa yeniden QR okutmaniz gerekir
  • Twilio ile birlikte kullanilabilir (Twilio basarisiz olursa bu devreye girer)
